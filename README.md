# STF CHALLENGE

Before starting you must check if you have a node version equal to or greater than **22.14.0** (do it with the `node -v` command) and an npm version equal to or greater than **10.9.2** (do it with the `npm -v` command).  


1. Go to the link [Download STF Challenge](https://github.com/Bushogun/STFGroupChallenge2/archive/refs/heads/main.zip)
2. Right click -> **Extract here**
3. Open folder **stfchallenge** in **Visual Studio Code**  
4. Change your directory to the path of **stfchallenge** and run : 
   ```bash
      npm install
      npm run dev
   ```
